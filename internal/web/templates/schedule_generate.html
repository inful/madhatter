Schedule Information

Automatic Maintenance:

The system automatically maintains a 14-day rolling schedule. This tool is for filling gaps or extending beyond the automatic window.

How it works:

  • Only generates assignments for dates without them (preserves existing)
  • Continues round-robin from the last assignment
  • Creates weekday assignments (Mon-Fri) only
  • Automatically skips weekends
